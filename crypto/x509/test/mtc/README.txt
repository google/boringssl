This directory contains test data for tests in crypto/x509/x509_test.cc related
to verifying Merkle Tree Certificates (MTCs).

Test certificates were generated by running the demo tool
github.com/ietf-plants-wg/merkle-tree-certs/demo at revision
7f5561c8f105f40fcb32a420825778eb2964759b.

The main corpus in this directory was generated using the demo tool with the
config at ./mtc_testdata_config.json. (The demo tool also generates unneeded
checkpoint and tile files, which are discarded.)

Other corpuses constructed for test data incompatible with the main corpus were
similarly generated from mtc_testdata_config.json in their respective
subdirectories.
